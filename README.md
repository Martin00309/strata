# Strata

An embedded, ordered, crash-safe key-value storage engine built on a
log-structured merge-tree (LSM). Pure Python, zero runtime dependencies.

> Status: early (0.1, alpha). The engine is functional and tested; the roadmap
> below tracks the work ahead.

Documentation is being written alongside the code — see
[docs/format.md](docs/format.md) for the on-disk format and
[ROADMAP.md](ROADMAP.md) for what's planned.
